# GPUI Component 介面遷移

使用者選擇 GPUI Component，並要求一起改善留白、字級和操作層級。沿用已驗證的錄影、MKV 救援、保留設定及安全關閉行為。

採用固定版本 gpui-kit 0.8.1（含 GPUI Component 與相容的 GPUI）。將錄影控制器從 eframe 分離，UI 使用 GPUI 的事件／視窗生命週期；背景工作及 GStreamer／FFmpeg 模組沿用。

視覺方案：淺色中性背景、白色卡片、藍綠色導覽、紅色錄影操作。960×720 起始視窗，左側導覽「錄影、救援、設定」；標題／說明／狀態與內容分層，減少常駐說明文字。主頁突出計時與錄影控制，音訊與品質選項分區。設定採一致的標籤、描述與開關。救援頁提供清楚的檔案清單與選擇／轉換操作。

保留 F9、GNOME 快捷鍵、應用程式選單整合、自動播放／開資料夾、錄製來源、音量增益、FPS／碼率、成功後保留 MKV，以及轉換進度。關閉請求須等待背景收尾，不可因 UI 更換重現原問題。

不新增帳號、雲端或剪輯功能，不修改既有影片。預設沿用使用者原有設定檔。
